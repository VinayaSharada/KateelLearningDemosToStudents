How to run

Colab or local Jupyter

Fastest: Colab (no install)

  1. Click any "Open in Colab" button above
  2. Colab opens the notebook live
  3. Run cells in order (Shift+Enter)
  4. Download outputs to your machine

Time: 3 hours end-to-end, live feedback

Local: Python + Jupyter

  1. Download each notebook (`.py` button)
  2. Ensure Python 3.8+ and Jupyter installed
  3. Open in Jupyter: jupyter notebook N1_Import_and_Validate.py
  4. Run cells top-to-bottom

Time: 3 hours + 10 min setup

Import to Colab (from here)

  1. Download all notebooks to your machine
  2. Upload to Google Drive
  3. Right-click file → Open with → Google Colaboratory
  4. Run in Colab, same as above

Time: 3 hours + 5 min upload
