🏦 Treasury Management Workshop

CFOPackV001: Treasury Decision Workshop

Build a complete treasury decision in 3 hours: forecast cash gaps, predict payment timing with ML, model working capital levers, and write a CFO-ready memo.

✓ 9 Jupyter notebooks (N0.5-N8) • 10K synthetic invoices ($546.9M AR) • No external APIs required
← Back to About Participant Guide

⚠️ Before You Start: Read the Participant Guide

This workshop requires preparation and context. Please read the Participant Guide before launching any notebooks. It covers:

  • Team formation & roles: Who does what (Analyst, Facilitator, Scribe)
  • What data you'll use: 10K synthetic invoices from 148 companies
  • How to load data: From GitHub OR upload your own
  • Workshop timeline: Realistic pacing and break points
  • What to bring: Laptop, Python 3.8+, and optional API key for enhanced analysis

Time needed: 3 hours (or 3h50min if including optional N0.5 Bank Reconciliation module)
