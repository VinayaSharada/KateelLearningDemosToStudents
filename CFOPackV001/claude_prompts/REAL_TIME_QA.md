# Real-Time Q&A Prompts

Use these **anytime** during the workshop when you're stuck, confused, or just
want a sanity check — not tied to a specific notebook.

---

## 1. Explain This Like I'm New to Treasury

```
Explain [term/concept, e.g. "days sales outstanding" or "hedge ratio"] like
I'm smart but new to treasury. Use a concrete number from my workshop data
if you can: [paste the relevant number or output].
```

---

## 2. Sanity-Check My Interpretation

```
Here's what I think this output means:
[state your interpretation in 1-2 sentences]

Here's the actual output:
[paste output]

Am I reading this correctly? What did I get wrong or oversimplify?
```

---

## 3. What Am I Missing?

```
I'm about to move to the next notebook. Before I do, here's where I've landed
so far:
[1-2 sentence summary of your finding/decision at this stage]

What question should I be asking that I'm not, given what I know so far?
```

---

## 4. Explain This Error

**When to use:** A notebook cell fails and the instructor is busy with another team.

```
This notebook cell failed with this error:
[paste the full error/traceback]

The cell is supposed to: [one sentence — what the cell does]

What's the likely cause, and what's the simplest fix? If it's a data issue
rather than a code issue, say so.
```
