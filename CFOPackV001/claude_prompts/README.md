# Claude Prompts

Optional, copy-paste prompts for using Claude alongside the CFOPackV001 notebooks.
None of these are required — the workshop and its notebooks work fully without them.

| File | Use it... |
|------|-----------|
| [PRE_PIPELINE.md](PRE_PIPELINE.md) | Before N1 — data quality, schema mapping, anonymization |
| [DURING_PIPELINE.md](DURING_PIPELINE.md) | After N2-N6 — interpreting each notebook's output |
| [POST_PIPELINE.md](POST_PIPELINE.md) | After N7-N8 — polishing the memo, stress-testing the plan |
| [REAL_TIME_QA.md](REAL_TIME_QA.md) | Anytime — general questions, debugging, "explain this" |

**How to use:** copy the prompt, paste your own notebook output where marked
in `[brackets]`, and send it to Claude (or any LLM you have access to).
