# Post-Pipeline Prompts

Use these **after N7-N8**, once you have a draft decision memo and implementation
plan and want to pressure-test them before presenting.

All prompts are optional — use them only if stuck or want a second opinion.

---

## 1. After N7: Decision Memo Polish

**When to use:** You have a generated or drafted decision memo and want it sharper before presenting.

```
Here's my draft CFO decision memo:

[paste the memo, or its Executive Summary + Recommendation sections]

1. Where is this vague, hedged, or burying the actual ask?
2. Rewrite the Executive Summary in 4 sentences max: problem, gap, recommendation,
   expected outcome.
3. What's the one number a CFO will ask about first, and is it prominent enough?
```

---

## 2. After N8: Operationalization Stress Test

**When to use:** You have an implementation plan and want to find the holes before you commit to it out loud.

```
Here's my implementation plan:

[paste task list with owners/timeline, or the monitoring/escalation table]

1. Which task has no clear owner or an unrealistic timeline?
2. What happens if the Week 1 milestone is missed — is the escalation path
   actually specific, or just "escalate to CFO"?
3. What's missing that a Controller would flag before approving this?
```

---

## 3. CFO Pushback Simulation

**When to use:** Right before you present, as a dry run for tough questions.

```
Act as a skeptical CFO reviewing this recommendation. Ask me the 5 hardest
questions you can think of, one at a time, and wait for my answer before
asking the next one.

Recommendation summary:
[paste your Executive Summary / recommended action + expected impact]

Start with the question you think is most likely to expose a weak spot.
```
