About Demo

P2P Process Mining Notebook

Colab companion that exposes the metric logic behind a fictional AP process-mining walkthrough.

Metric traceability for P2P process mining

Every key metric is calculated in visible Python cells so students can challenge the assumptions instead of accepting a black-box dashboard.

Shared data path

The notebook uses the same fictional Asteron AP event log as the browser workbench, which keeps the teaching story consistent across run modes.

What students should learn

  • How to reconstruct AP cases from an event log.
  • How to compare the happy path with actual process variants.
  • How to calculate lead time, queue time, rework, first-pass yield, and STP.
  • How to turn mined findings into transformation and control decisions.

Run modes

Colab

Open directly in Google Colab using the launch button.

Local notebook

Run locally from the repo checkout; the notebook looks for the bundled CSV before using GitHub raw fallback.

Browser pair

Use alongside the browser workbench when you want both high-level reveal and low-level metric transparency.

Self-service reuse

What you can enhance on your own

Add your own exception classes, amount bands, queues, and stakeholder views.

How to adapt this demo to your use case

Swap in sanitized AP data, confirm the metric definitions with local owners, and keep the interpretation under human review.

All data, targets, and examples are fictional and illustrative. Event-log analysis reveals behaviour patterns, not audited root cause.
