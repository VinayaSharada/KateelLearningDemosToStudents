What this demo is about

The notebook makes process-mining calculations inspectable: every variant, transition, delay, and control exception is computed from the AP event log in plain Python.

Why Colab helps here

Students can trace the metric definitions cell by cell and challenge the assumptions behind touch time, queue time, first-pass yield, and control exceptions instead of trusting a finished dashboard.

Self-Service Use

Useful for CFOs, finance-transformation teams, AP, procurement, controllership, faculty, and learners who want transparent process-mining calculations.

Start with the fictional event log, then replace it with sanitized AP events from your own process after revalidating the metric definitions.

Who else can use it

Notebook Flow

  1. Load the fictional AP event log from this repo.
  2. Reconstruct cases and compare the happy path with actual variants.
  3. Calculate lead time, touch time, wait time, rework, first-pass yield, and STP rate.
  4. Surface control exceptions, then map findings to eliminate, standardize, enable, assure, and monitor actions.
This is a teaching notebook. Event-log analysis reveals behaviour patterns, but it does not establish root cause or replace policy, control design, or finance judgement.
