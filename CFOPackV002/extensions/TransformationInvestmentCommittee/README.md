# Transformation Investment Committee

An optional half-day capstone for CFOPackV002. It transfers the evidence and
decision discipline of the Liquidity War Room into a broader CFO question:

> Which finance-transformation investment should be funded now, what follows
> next, and what must be proven in 90 days before more capital is released?

This is a separate lab, not N9. Complete it after the Liquidity War Room or use
it as a second-day executive capstone.

## Participant path

1. Read `CASE_BRIEF.md` and the initiative cards.
2. Complete `PARTICIPANT_CANVAS.md` without searching for a model answer.
3. Run `T1_Transformation_Investment_Committee.ipynb`.
4. Select one `NOW` investment and one `NEXT` investment within the mandate.
5. Define a measurable 90-day proof point and a stop/scale gate.
6. Submit the generated Board memo and benefits-realization tracker.

All organizations, costs and benefits are synthetic. The case is intended to
teach constrained judgment, not prescribe technology investments.
