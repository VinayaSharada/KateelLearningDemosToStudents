Faculty quick start

Make the demos highly used in class

Before class

  1. Pick one course path.
  2. Select 2-3 demos aligned to the session outcome.
  3. Open the About Demo pages and copy the faculty prompt.

During class

  1. Read the objective together.
  2. Launch the actual demo.
  3. Ask students to toggle AI or change a scenario.

After class

  1. Collect one insight and one limitation.
  2. Ask students to rate the About Demo page.
  3. Notify usage to vinallcontact@gmail.com.
