Learning Objectives

What students learn in this lab

1. Grad-CAM Visual Saliency

Compute gradients of target class scores with respect to feature maps in final convolutional layers to generate semantically grounded visual explanation heatmaps.

2. FGSM Adversarial Crafting

Formulate Goodfellow's Fast Gradient Sign Method (FGSM) to compute worst-case $L_\infty$-bounded input perturbations that maximize cross-entropy loss in a single gradient step.

3. Iterative PGD Attacks

Implement Projected Gradient Descent (PGD), the universal first-order adversarial adversary, projecting back onto the $\epsilon$-ball after each inner gradient step.

4. Adversarial Defense & Tradeoffs

Implement Madry's min-max adversarial training formulation and evaluate the inevitable trade-off between clean test accuracy and robust adversarial accuracy.

Mathematical Formulations

Vision XAI & Adversarial Equations

Grad-CAM Weight & Heatmap

Importance weight $\alpha_k^c$ for feature map $A^k$ and target class $c$:

α_k^c = (1 / Z) · ∑_i ∑_j (∂y^c / ∂A_{i,j}^k)

L_{Grad-CAM}^c = ReLU( ∑_k α_k^c · A^k )

Applies ReLU to highlight only features that positively correlate with class score.

FGSM Perturbation Formula

Crafting adversarial sample $x_{adv}$ bounded by max perturbation $\epsilon$:

x_adv = x + ε · sign( ∇_x L(θ, x, y) )

Moves each input pixel along the direction that most steepens the classification loss.

Madry Robust Min-Max Objective

Adversarial training formulates model optimization as a saddle point problem:

min_θ E_{(x,y)} [ max_{δ ∈ S} L(θ, x + δ, y) ]

Trained weights withstand worst-case perturbations within ball $S = \{\delta : ||\delta||_\infty \le \epsilon\}$.

Faculty Teaching Prompts

Classroom Discussion & Reflection

During Class Activity

Have students use the interactive perturbation slider. Start with $\epsilon = 0.02$ (imperceptible noise) and observe how the Grad-CAM activation heatmap shifts from the object center to background noise, causing a confidence collapse.

Safety & Robustness Prompt

"In autonomous vehicles or medical imaging diagnostics, why is high standard test accuracy completely insufficient without certified or empirical adversarial robustness bounds?"

Take-Home Assignment Prompt

Students submit attack success rate curves against $\epsilon \in [0.0, 0.3]$ and evaluate adversarial training defense in Webinar 04 Student Assignment Prompt.
