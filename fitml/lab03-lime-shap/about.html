Feature Attribution (LIME & SHAP)

Deconstruct black-box machine learning models into local and global explanations using cooperative game theory (SHAP) and local sparse linear surrogates (LIME).

Learning Objectives

What students learn in this lab

1. Game-Theoretic Foundations

Understand how Shapley values uniquely satisfy the four axiomatic properties of fair attribution: Efficiency, Symmetry, Dummy Player, and Additivity.

2. Local vs Global Interpretability

Distinguish local explanations (why did this customer get denied?) from global explanations (what are the top risk drivers across the whole portfolio?).

3. LIME Perturbation Surrogates

Generate perturbations around an instance, weight them with an exponential distance kernel, and train an interpretable sparse linear surrogate model.

4. Auditing Model Reliability

Identify confounding variables, shortcut learning, and data leakage where a model achieves high accuracy by relying on illegitimate proxy features.

Mathematical Formulations

Attribution Mechanics

Shapley Value Definition

The marginal contribution of feature $i$ across all possible coalitions $S \subseteq F \setminus \{i\}$:

ϕ_i(v) = ∑ [|S|!(|F| - |S| - 1)! / |F|!] · [v(S ∪ {i}) - v(S)]

Guarantees that the sum of attributions equals the total deviation from base value: $\sum \phi_i = f(x) - E[f(X)]$.

LIME Surrogate Objective

Minimize unfaithfulness of simple model $g \in G$ within local neighborhood $\pi_x(z)$:

arg min_g L(f, g, π_x) + Ω(g)

where $\pi_x(z) = \exp(-D(x,z)^2 / \sigma^2)$ measures proximity to instance $x$.

Waterfall Attribution

Visualizing baseline prior $E[f(x)]$ moving to prediction $f(x)$:

f(x) = E[f(X)] + ϕ_1 + ϕ_2 + ... + ϕ_M

Positive SHAP values push towards higher risk, negative values reduce risk.

Faculty Teaching Prompts

Classroom Discussion & Reflection

During Class Activity

Select an individual with a borderline credit score. Have students compare the LIME top-3 explanations with the TreeSHAP waterfall plot. Ask why the two methods might slightly disagree on feature ranking.

Auditing Question

"How does a SHAP summary plot allow a risk officer to detect model leakage (e.g. an internal ID column mistakenly included in training) that cross-validation missed?"
