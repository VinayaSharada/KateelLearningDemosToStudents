How to teach with this course

About Demo first, actual demo second

Every demo card opens the About Demo page. From there, students can launch the interactive app when they are ready to practice.

1 Read

Understand the objective, concepts, and expected output.

2 Practice

Launch the actual demo and change inputs or scenarios.

3 Reflect

Explain the insight, limitation, and next action.

Learning outcomes

What this course builds

Core outcomes

  • Explain retrieval, generation, and grounding in RAG systems.
  • Evaluate answer quality using evidence and hallucination checks.
  • Compare text, voice, graph, and page-index retrieval patterns.
  • Design prompts and retrieval workflows for learning use cases.

Faculty prompt

Require learners to cite the retrieved evidence before accepting any generated answer.
