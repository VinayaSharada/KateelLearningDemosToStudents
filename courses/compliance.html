Teaching flow

Start from the pack, not the folder tree

This course pack collects the curated public demos for this theme and links them to the right supporting course and assignment resources.

1 Open a demo unit

Use the About page for context, expectations, and teaching prompts.

2 Launch when ready

Move into the interactive demo only after the setup and run mode make sense for the class.

3 Extend with assignments

Use the linked assignment scaffold when you want written analysis, reflection, or grading.

Learning outcomes

What this course pack builds

Core outcomes

  • Interpret governance, policy, AML, and model-monitoring outputs responsibly.
  • Connect signal detection to control design and escalation choices.
  • Distinguish detection, decision, accountability, and documentation layers.
  • Use demo outputs to discuss oversight rather than just automation quality.

Audience fit

AI governance, AML, regulation, model risk

Curated public packClassroom ready

Faculty prompt

Ask students to identify the governance or regulatory decision behind the output, not just the signal itself.
