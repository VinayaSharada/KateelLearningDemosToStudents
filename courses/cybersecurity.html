Teaching flow

Start from the pack, not the folder tree

This course pack collects the curated public demos for this theme and links them to the right supporting course and assignment resources.

1 Open a demo unit

Use the About page for context, expectations, and teaching prompts.

2 Launch when ready

Move into the interactive demo only after the setup and run mode make sense for the class.

3 Extend with assignments

Use the linked assignment scaffold when you want written analysis, reflection, or grading.

Learning outcomes

What this course pack builds

Core outcomes

  • Interpret security events, threat models, and scan outputs in context.
  • Connect observed risk to detection, prioritization, and remediation choices.
  • Compare static indicators with scenario-driven security reasoning.
  • Recognize the difference between activity, evidence, and confirmed compromise.

Audience fit

IoT, network, malware, threat modeling

Curated public packClassroom ready

Faculty prompt

Have students explain which observed signal is most actionable, which control they would recommend next, and what evidence they still need.
