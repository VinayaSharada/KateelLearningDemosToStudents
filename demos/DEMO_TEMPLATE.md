# Demo Page Template

Use this template for all KateelLearningDemos pages.

## Page Structure

1. **Learning Objectives** - What students will learn
2. **Key Features** - Interactive elements and capabilities
3. **Scenarios Included** - Use cases covered
4. **Courses Applicable** - Which courses use this demo
5. **How to Run** - Instructions (link for browser demos, steps for non-browser)
6. **Resources** - README, Source Code, Report Issues links
7. **Attribution** - Creator, email, course, module
8. **Footer** - Standard footer with attribution

## Browser-Based Demo

For browser-based demos, the "How to Run" section should be:

```html
<div class="card">
  <h3>🎓 How to Run</h3>
  <p>Click the button below to launch the demo directly in your browser:</p>
  <a href="demo.html" class="btn btn-primary">▶️ Run Demo Now</a>
</div>
```

## Non-Browser Demo

For demos requiring local setup:

```html
<div class="card">
  <h3>🎓 How to Run</h3>
  <p>This is a documentation-based demo. To use:</p>
  <ol>
    <li>Clone the repository</li>
    <li>Navigate to the demo folder</li>
    <li>Read the README.md for detailed instructions</li>
  </ol>
</div>
```
