# Demo Template

This is the template for creating new demo pages with consistent navigation.

## Usage

1. Copy `template.html` to your demo directory
2. Replace placeholders:
   - `{{DEMO_TITLE}}` - Demo name
   - `{{DEMO_SUBTITLE}}` - Brief description
   - `{{DEMO_DESCRIPTION}}` - Meta description
   - `{{DEMO_CONTENT}}` - Your demo HTML/content
   - `{{STYLE_PATH}}` - Path to your CSS (usually `style.css`)
   - `{{COURSE_PAGE}}` - Link to course page
   - `{{COURSE_NAME}}` - Course name

## Navigation Paths

From demo directories, use these relative paths:
- Landing Page: `../../index.html`
- Treasury Course: `../../courses/treasury-management.html`
- AI/ML Course: `../../courses/ai-ml-workflows.html`
- GitHub: `https://github.com/VinayaSharada/KateelLearningDemosToStudents`
