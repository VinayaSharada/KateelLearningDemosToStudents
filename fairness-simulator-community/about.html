Mathematical Formulations

The Five Slicing Cuts & Quantitative Metrics

⚡ Marginal Row Cut: Demographic Parity

Measures positive outcome rate equality regardless of ground truth status:

SR = (TP + FP) / N

DIR = SR(A=0) / SR(A=1) ≥ 0.80 (EEOC Four-Fifths)

SPD = SR(A=0) - SR(A=1) (Parity when SPD = 0)

🟢 Top Row Cut: Equal Opportunity (TPR)

Measures equality of recall among qualified individuals ($Y=1$):

TPR = TP / (TP + FN)

EOD = |TPR(A=0) - TPR(A=1)|

Guarantees equal opportunity of being selected when qualified.

🔴 Bottom Row Cut: Predictive Equality (FPR)

Measures equality of false positive error rates among non-qualified candidates ($Y=0$):

FPR = FP / (FP + TN)

ΔFPR = |FPR(A=0) - FPR(A=1)|

Critical in criminal recidivism (COMPAS) and punitive AI models.

🔵 Left Column Cut: Predictive Parity (PPV)

Measures positive predictive value (precision) calibration:

PPV = TP / (TP + FP)

ΔPPV = |PPV(A=0) - PPV(A=1)|

Ensures a positive prediction carries the same probability of success across groups.

🟣 Diagonal Cut: Accuracy Equality

Measures overall classification correctness across groups:

Acc = (TP + TN) / N

ΔAcc = |Acc(A=0) - Acc(A=1)|

Evaluates whether model fidelity is uniform across demographic lines.

⚖️ Impossibility Theorems (Kleinberg / Chouldechova)

When base rates differ between groups ($P(Y=1|A=1) \neq P(Y=1|A=0)$), it is mathematically impossible to simultaneously satisfy:

  • Equalized Odds (TPR and FPR equality)
  • Predictive Parity (PPV calibration)

Unless the classifier achieves 100% perfect prediction accuracy (Oracle mode).

Faculty Teaching Prompts

Classroom Discussion & Reflection Scenarios

Scenario 1: Standard Hiring Disparity

Load the default preset ($DIR = 0.50$). Have students identify which slice button clearly exposes the Title VII adverse impact violation. Ask how adjusting the decision threshold changes the False Positive Rate.

Scenario 2: The Base Rate Conflict

Adjust Group base rate ($P(Y=1)$) to 60% for Men and 30% for Women. Challenge students to find any classifier setting that satisfies both Equal Opportunity and Predictive Parity without forcing an oracle classifier.

Scenario 3: Audit Report Submission

Have students click Copy Audit Table and paste the resulting markdown into their assignment submission, explaining which metric should take legal precedence in an automated credit scoring system.
