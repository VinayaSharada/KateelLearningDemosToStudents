## 🎯 Overview

The **Interactive Algorithmic Fairness Simulator (Community Edition)** is a standalone, single-file interactive laboratory designed to build visual intuition around how algorithmic bias and discrimination emerge in machine learning models.

Key capabilities included in this community version:
1. **The Three-Matrix Live Simulator:** Simultaneously inspect and manipulate the Confusion Matrices for:
   - **Privileged Group ($A=1$ / Men)**
   - **Unprivileged Group ($A=0$ / Women)**
   - **Overall Combined Population**
2. **Interactive "Three Cuts" Slicing Buttons:**
   - ⚡ **Marginal Row Cut:** Visualizes Demographic Parity & Disparate Impact Ratio ($DIR$)
   - 🟢 **Top Row Cut:** Visualizes True Positive Rate Parity (Equal Opportunity / Recall)
   - 🔴 **Bottom Row Cut:** Visualizes False Positive Rate Parity (Predictive Equality / Fallout)
   - 🔵 **Left Column Cut:** Visualizes Positive Predictive Value (Predictive Parity / Precision Calibration)
   - 🟣 **Diagonal Cut:** Visualizes True Accuracy Equality
3. **Real-Time Regulatory Compliance Table:** Computes EEOC Title VII Four-Fifths Rule compliance in real time.
4. **Instant Markdown Export:** One-click clipboard export for lab reports, student assignments, and blog posts.
