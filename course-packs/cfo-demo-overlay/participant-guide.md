# CFO Demo Overlay Participant Guide

## Goal

Use the demos to answer five recurring finance questions:

- Is the value case credible?
- Are the controls strong enough?
- Is ownership and evidence explicit?
- What still needs human judgement?
- What should finance do next?

## How to use the overlay

1. Start with the business decision, not the technology.
2. Open the About page before launching the demo.
3. Use the self-service sections to adapt the demo to your own context.
4. Capture the next decision, owner, and review point before moving on.
