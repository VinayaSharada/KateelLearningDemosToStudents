# CFO Demo Overlay Instructor Guide

## Purpose

Run the cross-cutting CFO overlay in a reusable sequence:

1. Value case
2. Governance and decision record
3. Workflow and controls
4. Evidence and commentary
5. Close, reconciliation, and signal judgement
6. O2C, P2P, and treasury operating discipline

## Suggested sequence

- `AIROICalculator`
- `AIGovernanceScorecard`
- `AIDecisionTracker`
- `AIWorkflowDemo`
- `AIContentSummarizer`
- `LiteParseDemo`
- `MonthEndCloseCommandCenter`
- `FinanceEvidenceAndDataLineageChallenge`
- `DigitalFinancePortfolioSimulator`
- `FinanceSignalTriage`
- `PaymentReconciliationWorkbench`
- `O2CProcessMiningWorkbench`
- `P2PProcessMiningWorkbench`
- `InvoiceLevelCollectionsPrediction`
- `TreasuryControlTower`

## Teaching note

This overlay should not replace domain packs. Use it when the audience is decision-led and multi-stakeholder rather than domain-specialist.
