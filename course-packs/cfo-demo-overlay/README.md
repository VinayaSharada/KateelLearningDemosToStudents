# CFO Demo Overlay

Cross-cutting overlay for CFO, controllership, treasury, and finance-transformation decisions.

## Files

- `course.json`
- `demo-pack.json`
- `participant-guide.md`
- `instructor-guide.md`

## What makes this an overlay

- The demos stay in their original folders and domain packs.
- This pack re-curates them for a CFO-facing audience and decision flow.
- A single demo can appear in Treasury, AI/ML, Compliance, or CFO overlay contexts without duplication.
