# O2C Process Mining Notebook Fallback

Use this fallback when Colab is unavailable.

## What the notebook demonstrates

- How a fictional Order-to-Cash event log is loaded and grouped into cases
- How the happy path is compared with actual variants
- How lead time, wait time, rework, first-pass yield, STP, and control exceptions are calculated
- How those outputs support eliminate, standardize, enable, assure, and monitor decisions

## Teaching note

The notebook is valuable because students can inspect the logic behind the metrics instead of only consuming a finished dashboard. Keep the discussion on business interpretation and control implications, not on Python syntax.
