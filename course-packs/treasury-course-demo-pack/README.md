# Treasury Course Demo Pack

This folder contains a reusable demo-pack scaffold for treasury teaching sessions.

## Files

- `course.json`
  - Pack-level metadata and purpose.
- `demo-pack.json`
  - The core treasury teaching sequence.
- `extension-pack.json`
  - Downstream automation, GenAI, and governance exercises that can reuse treasury outputs.
- `participant-guide.md`
  - Learner-facing instructions and outputs.
- `instructor-guide.md`
  - Faculty runbook, timing, and fallback guidance.
- `assets/`
  - Pack-local static assets such as fallback screenshots or completed-run PDFs.
