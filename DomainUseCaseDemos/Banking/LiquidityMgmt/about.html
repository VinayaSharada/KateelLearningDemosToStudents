Liquidity Management

Use this page to choose the right teaching mode and frame the simulation before students run the notebook or Python scripts.

Colab Local Python

Mode Guidance

Colab mode

Best for immediate classroom access and for showing the simulation steps in Python without environment setup issues.

Local mode

Best for advanced learners who need to edit the generator, risk metrics, or Monte Carlo logic directly.

Why no browser yet

This workflow is compute-heavy enough that a browser version should be designed deliberately rather than rushed into a weaker copy.

What students should learn

Core concept

Liquidity risk depends on timing, volatility, and downside tails, not just expected average flow.

What to notice

Students should compare mean outcomes with VaR and shortfall probability to see why treasury needs buffers.

Discussion prompt

Ask what minimum liquidity buffer the institution should hold and which assumptions most influence that recommendation.
