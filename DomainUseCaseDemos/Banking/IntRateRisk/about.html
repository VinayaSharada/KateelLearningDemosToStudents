Interest Rate Risk

This demo now supports browser, Colab, and local Python modes so instructors can choose between fast concept teaching and deeper code-based analysis.

Browser Colab Local Python

Mode Guidance

Browser mode

Best for short classes, live scenario testing, and explaining repricing logic without setup delays.

Colab mode

Best for a guided Python workflow with synthetic data generation, pandas analysis, and charting in one notebook.

Local mode

Best for modifying the data generator or extending the analysis script directly in code.

What students should learn

Core concept

Small rate changes can produce large balance-sheet effects when exposure is concentrated in products with higher carrying cost.

What to notice

Students should compare account-type concentration, weighted rate, and shock delta together rather than reading only one output.

Discussion prompt

Ask which repricing action, pricing change, or hedging response would matter most if the current shock scenario persisted for a full year.
