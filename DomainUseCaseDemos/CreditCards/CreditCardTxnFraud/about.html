What this demo is about

Modeling card fraud with visible features

This local workflow complements browser fraud demos by exposing the underlying Python pipeline, synthetic data generation, and classification logic used to flag suspicious card transactions.

Learning objectives

  • Explain how transaction features are engineered for card-fraud detection.
  • Compare fraud-loss reduction with false-positive and customer-friction trade-offs.
  • Recognize the difference between classroom synthetic data and real auth-stream complexity.

Run mode

  • Supported mode: Local Python
  • Uses repository scripts and dependencies, not a browser-only simulation.

Teacher cue

Ask which variables would actually be present at authorization time versus only after later investigation. That keeps the class grounded in real payment operations.
