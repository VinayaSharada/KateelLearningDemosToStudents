Digital Payments • Local Python • 30-40 min

Credit Card Transaction Fraud

This folder is a local Python workflow rather than a browser simulation. Use the steps below to generate synthetic data, run the classifier, and discuss feature quality versus real-time fraud operations.

Recommended steps

  1. Read Readme.MD for setup expectations.
  2. Install dependencies from requirements.txt.
  3. Generate synthetic data with generate_synthetic_data.py.
  4. Run fraud_detection_classification.py.

What to notice

  • Which features are available before authorization versus after settlement or investigation.
  • How threshold changes alter fraud capture and false positives.
  • Why synthetic data helps teach logic but cannot stand in for production fraud telemetry.
