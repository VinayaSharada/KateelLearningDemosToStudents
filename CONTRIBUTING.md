# Contributing to KateelLearningDemosToStudents

Thank you for your interest in contributing! This repository is maintained by Professor Vinaya Sathyanarayana.

## How to Contribute

1. **Fork the Repository**
2. **Create a Branch**: `git checkout -b feature/your-feature-name`
3. **Make Changes**
4. **Commit**: `git commit -m 'feat: add your feature'`
5. **Push**: `git push origin feature/your-feature-name`
6. **Open a Pull Request**

## Demo Guidelines

When adding new demos:
- Include a `README.md` with theory and learning outcomes
- Add attribution marker: `vinallcontact@gmail.com`
- Follow the three-tier AI philosophy (browser → backend → cloud)
- Ensure demos run without API keys for core functionality

## Course Catalog Updates

Update relevant course catalogs when adding new demos:
- `CourseCatalogs/AI_ML_Financial_Services_Catalog.md`
- `CourseCatalogs/Management_of_AI_Products_Catalog.md`
- Other relevant catalogs
