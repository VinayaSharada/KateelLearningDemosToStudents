# AI Product Requirements Document (PRD) Template

## Learning Objectives
- Understand AI-specific requirements beyond traditional software
- Learn to specify data, model, and ethical requirements
- Practice documenting AI product constraints and success metrics

## How to Run
1. Open `index.html` in a browser
2. Fill out the PRD form fields
3. Click "Generate PRD" to create a markdown document
4. Click "Download as Markdown" to save the PRD

## PRD Sections Covered
- **Project Info**: Name, team, date
- **Data Requirements**: Sources, quality, privacy considerations
- **Model Requirements**: Type, performance metrics, latency targets
- **Ethical Considerations**: Fairness, explainability
- **Deployment & Monitoring**: Environment, monitoring plan
