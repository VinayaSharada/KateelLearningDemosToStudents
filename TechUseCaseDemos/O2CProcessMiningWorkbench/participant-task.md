# Participant Task

## Scenario

You are reviewing fictional O2C operations at Asteron. Management assumed the process was clean and five-step. The event log shows otherwise.

## Your task

1. Review the happy path and the actual process variants.
2. Filter to one exception type or high-value band.
3. Decide which friction should be removed, standardized, enabled with workflow, or retained as human judgement.
4. State what the finance team should monitor after the change.

## Deliverable

Give a short answer covering:

- the biggest source of avoidable delay
- whether the issue is upstream discipline, workflow routing, or judgement-heavy exception handling
- one action owner
- one 30-day proof point
- one trigger that should remain monitored after launch
