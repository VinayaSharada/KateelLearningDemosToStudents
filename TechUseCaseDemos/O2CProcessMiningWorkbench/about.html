What this demo is about

Transformation starts with the executed flow, not the designed flow

The demo uses a fictional Asteron O2C event log to show the difference between the assumed order-to-cash process and the actual one. Instead of beginning with tooling, it begins with path complexity, queue time, rework, and control exceptions.

Learning objectives

  • Explain how process mining reveals the real O2C path rather than the designed one.
  • Interpret lead time, wait time, rework, and exception ageing in finance language.
  • Separate eliminate, standardize, enable, assure, and monitor actions from one another.

Run mode

  • Supported mode: Browser
  • Demo type: local interactive workbench
  • Primary launch surface: index.html

Teacher cue

Ask: “Is this really an automation problem, or is it an upstream discipline problem that automation would simply accelerate?”

Business decision

What decision this demo helps you make

Use this demo to decide what should be removed, standardized, enabled with workflow, retained as human judgement, or monitored through operating triggers before the organization invests in automation.

Self-service reuse

What you can build on from here

What you can enhance on your own

  • Add more entities, payment-term variants, or dispute types once the base event-log flow is clear.
  • Add richer DSO or cost-of-delay assumptions for executive discussion.
  • Add exportable action packs for process owner, controller, and treasury audiences.

How to adapt this demo to your use case

  • Replace the fictional Asteron event log with sanitized O2C events from your own organization or course setting.
  • Revalidate metric definitions and SLA thresholds with finance, operations, and controller owners.
  • Keep the output diagnostic until the organization confirms the root cause and control boundary.

Audience fit

This demo supports CFO workshops, treasury, controllership, shared services, operations, and faculty audiences because O2C delays affect cash, controls, and customer outcomes together.
