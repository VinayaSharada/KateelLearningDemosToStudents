# AI Governance Scorecard

Browser-based finance-governance demo for deciding whether an AI-enabled finance process is ready for deployment, should remain in pilot mode, or needs remediation first.

## Decision focus

The demo is designed around one finance question:

`Are the CFO control requirements strong enough to allow controlled deployment of this AI-supported process?`
