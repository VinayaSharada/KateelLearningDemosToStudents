Why Bitcoin (Before Ethereum)

Bitcoin's Key Insight: Use computational proof-of-work to create trustless consensus. No central authority needed.

How It Works: Miners compete to find a nonce (number used once) such that the block header's SHA-256 hash meets a difficulty target. First to solve it gets to add the block.

For Finance: This creates an economic barrier to attacking the network. Rewriting history would cost billions in electricity and hardware—more expensive than stealing the funds.

Block Structure

  • Version: Protocol version (currently 4)
  • Prev Hash: Links to prior block (chain immutability)
  • Merkle Root: Hash of all transactions
  • Timestamp: When block created
  • Difficulty: How many leading zeros required
  • Nonce: The mining variable

Mining Economics

  • Hardware: ASICs cost $1000+ per machine
  • Electricity: $0.01-0.10 per hash globally
  • Reward: 6.25 BTC (~$150,000) per block
  • Difficulty: Adjusts every 2 weeks to maintain 10-min blocks

Why Ethereum Matters

Bitcoin's Limitation: "Move money from A to B" is all Bitcoin can really do. It's like a bank ledger.

Ethereum's Innovation: Account model + Turing-complete programming. Now you can build financial contracts, not just transactions.

For Finance: This enables DeFi. Lending protocols, decentralized exchanges, derivatives, insurance—all governed by smart contracts, no middleman.

Gas Economics

  • Transfer = 21,000 gas (~$0.50 at 20 gwei)
  • Contract deploy = 53,000+ gas
  • DEX swap = 150,000+ gas
  • During congestion: gas 10-100x higher

Smart Contracts: Code = Law

Smart Contract: Code that runs on the blockchain. Once deployed, it's immutable—no one can change its logic.

Solidity: The primary language for Ethereum contracts. Similar to JavaScript but must be formally verified (audited) because bugs = lost funds.

For Finance: Complex financial products (options, loans, derivatives) execute automatically when conditions are met. No lawyer, no bank, no delay.

Real DeFi Examples

  • Uniswap: Decentralized exchange using constant-product formula (x*y=k)
  • Aave: Lending protocol: deposit assets, earn interest
  • MakerDAO: Stablecoin collateralized by crypto

Common Risks

  • Reentrancy: Attacker calls you while you're still processing
  • Overflow: Number exceeds max uint256, wraps to 0
  • Front-running: Attacker sees your transaction, mines theirs first

NFTs: Ownership on Chain

NFT (ERC-721): Uniquely identified token. Contract stores who owns each tokenId. Ownership is immutable and verifiable on-chain.

ERC-1155: "Multi-token standard" - single contract can hold both fungible and non-fungible tokens. Better for gaming.

For Finance: Fractional ownership of expensive assets (art, real estate). Use NFTs as loan collateral. Automate royalties on secondary sales.

Real Collections

  • Bored Ape: 10,000 unique apes ($50K floor)
  • CryptoPunks: Pioneering 8-bit art NFTs
  • Art Blocks: Generative algorithmic art

Economics

  • Creator Royalties: Typically 2-10% on resales
  • Platform Fee: 2.5% (OpenSea standard)
  • Fractional NFTs: Split expensive assets into many shares

How to Use This Demo

1. Bitcoin (15 min)

Start here. Increment the nonce and watch the SHA-256 hash change. Try to find a hash that starts with 2+ zeros. This is mining.

2. Ethereum (15 min)

Compare account vs UTXO models. Calculate gas costs for real transactions. See why computation has a price.

3. Contracts (30 min)

Read Solidity code (ERC-20, voting, DEX). See it compile to bytecode. Execute functions and watch state change.

4. NFTs (20 min)

Compare ERC-721 and ERC-1155. Mint an NFT. Calculate royalties. Understand fractional ownership.
