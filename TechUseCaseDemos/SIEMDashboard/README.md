# SIEM Dashboard

## Learning Objectives
- Understand Security Incident and Event Management principles
- Learn to interpret security alerts and prioritize responses
- Practice threat analysis and incident response workflows
- Understand AI-driven security analytics

## How to Run
1. Open `index.html` in a browser
2. View the dashboard statistics
3. Review active security alerts (sorted by severity)
4. Examine recent security events in the table

## Features
- **Real-time Statistics**: Total events, active alerts, critical alerts, resolved incidents
- **Alert Prioritization**: Color-coded alerts (Critical, High, Medium, Low)
- **Event Timeline**: Recent security events with source/destination details
- **Refresh Capability**: Simulate new data arrival

## Key Security Concepts
- **SIEM**: Centralized security monitoring and analysis
- **Alert Triage**: Prioritizing incidents by severity and business impact
- **Log Analysis**: Correlating events across multiple sources
- **Incident Response**: Workflow for handling security events
