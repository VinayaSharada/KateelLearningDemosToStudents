# Dell vs Competitors Working Capital Case

## Overview

Browser-based treasury case comparing Dell, HP, Lenovo, and Apple using revenue, DSO, DIO, DPO, and cash conversion cycle.

## Learning objectives

- Explain how receivables, inventory, and payables shape cash conversion cycle.
- Estimate how much cash is tied up or released by operating-policy changes.
- Compare which working-capital lever is easiest versus hardest to copy competitively.
- Discuss where aggressive payables strategy creates financial benefit but operational risk.

## How to run

- Browser: open `index.html`.
