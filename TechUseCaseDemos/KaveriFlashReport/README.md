# Kaveri Enterprise Flash — Capstone Simulation

Browser-first capstone: four sibling demos (working capital, supply chain,
M&A diligence, cyber incident) all happened to the same fictional company in
the same quarter. This pane assembles them: a status per lens, the numbers
that matter, where the risks compound across functions, and one decisions
register — 16 decisions, each with an owner, zero executed by agents. All
content pre-computed and synthetic; no network calls, no keys.

## Learning objectives

- AI reimagination is an enterprise property (the couplings between
  functions), not a use-case list.
- The decisions register is the governance thesis in one table:
  agent-prepared, human-decided (16:0).
- The pane was the cheapest demo to build because the lenses already spoke
  one governed data dialect — architecture is the moat.

## Run modes

- **Browser** (this folder): open `index.html`. No setup.
- **Live tier**: registered executive-education participants re-run any lens
  and the flash re-assembles in seconds; a Chief-of-Staff agent swarm writes
  the CEO's Monday note.

## Expected setup time

0 minutes (browser). Demo type: capstone dashboard simulation with lens
tiles, the flash report, compounding-risk analysis and a decisions register.

## Files in this folder

`index.html` · `about.html` · `app.js` · `data.js` (pre-computed synthetic

## How to run

Open `index.html` in any modern browser, or serve the folder statically.

*All data synthetic; no real person or company records.*
