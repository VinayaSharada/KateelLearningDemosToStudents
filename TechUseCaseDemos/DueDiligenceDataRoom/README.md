# Project Anvil — Due-Diligence Data Room Simulation

Browser-first demo: a fictional acquisition at an ₹85 cr ask that the
seller's numbers genuinely support — until diligence finds eight red flags
and bridges the value down to ₹62.8 cr (bear case ₹24 cr). Includes the
actual contract extracts the legal agent reads, and the committee's verdict:
renegotiate at ≤₹59.6 cr with conditions precedent, or walk. All results
pre-computed and synthetic; no network calls, no keys.

## Learning objectives

- Grain reveals what aggregates hide: flat annual revenue, shrinking monthly
  volumes, price increases in between.
- Findings must land as price: the bridge converts eight risks into one
  negotiating position.
- Institutionalized red-teaming: a sponsor agent argues the honest bull
  case, an adversarial auditor attacks it, and neither may invent a number.

## Run modes

- **Browser** (this folder): open `index.html`. No setup.
- **Live tier**: registered executive-education participants get the full
  data-room scanner and the sponsor-vs-auditor agent committee, re-runnable
  on fresh seeds or an anonymized real deal.

## Expected setup time

0 minutes (browser). Demo type: interactive simulation with red-flag
accordion, valuation bridge, scenario comparison and contract extracts.
