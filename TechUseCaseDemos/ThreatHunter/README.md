# AI Threat Hunter

## Learning Objectives
- Understand ML-powered security log analysis
- Learn anomaly detection for threat hunting
- Practice identifying security patterns in logs
- Understand risk scoring methodologies

## How to Run
1. Open `index.html` in a browser
2. Click "Upload Log File" or drag & drop a log file
3. Click "Analyze Logs"
4. Review detected anomalies and risk score

## Supported Log Formats
- Plain text logs
- CSV format
- JSON logs

## Anomaly Types Detected
- **Authentication Anomalies**: Failed logins, brute force attempts
- **Network Anomalies**: Port scans, unauthorized connections
- **Malware Indicators**: Signature matches, suspicious activity
- **Data Loss Indicators**: Exfiltration attempts, large transfers

## AI Detection Approach
This demo simulates ML-based anomaly detection by:
1. Tokenizing log entries
2. Comparing against known attack patterns
3. Scoring based on severity
4. Ranking by risk impact
