# Expected Answer

## Strong answer pattern

- Approve when the confidence-adjusted value remains positive, payback is acceptable, and control remediation is included in the economics.
- Phase when the upside is credible but adoption or confidence is still uncertain.
- Hold when the base economics rely on unrealistic adoption, weak evidence, or missing controls.

## What a good participant answer includes

- value case
- payback view
- benefit-confidence range
- control or governance limitation
- named owner
- approval point
