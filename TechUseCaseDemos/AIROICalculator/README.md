# AI ROI Calculator

Browser-based finance-transformation demo for evaluating whether an AI initiative deserves CFO funding now, should be phased, or should be held until evidence and controls improve.

## Decision focus

The demo is designed around one finance question:

`Does this initiative create confidence-adjusted value after implementation, adoption, and control-remediation costs are included?`
