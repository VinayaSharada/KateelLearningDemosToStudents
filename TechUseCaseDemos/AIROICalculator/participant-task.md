# Participant Task

## Scenario

You are helping the CFO evaluate a finance-transformation initiative that uses AI to reduce manual work and improve operating capacity.

## Your task

1. Review the default assumptions.
2. Change adoption or confidence assumptions.
3. Decide whether the initiative should be approved now, phased, or held.
4. State the value case, the main risk, and the approval condition.

## Deliverable

Provide a short recommendation covering:

- decision
- payback period
- confidence-adjusted value
- key control concern
- owner
- evidence needed before approval
