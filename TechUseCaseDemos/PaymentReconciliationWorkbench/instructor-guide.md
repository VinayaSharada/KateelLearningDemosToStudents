# Instructor Guide

## Business decision

Decide whether finance can close or release settlement results, which exceptions are material, and who owns resolution.

## Facilitator mode

Time: `5-8 minutes`

1. Generate the default queue.
2. Point out unmatched value, aged exceptions, and materiality threshold.
3. Ask which exception should block close.
4. Reveal the expected answer and discuss the approval point.

## Participant exercise

Time: `10 minutes`

Ask participants to:

1. Change the scenario inputs.
2. Identify the highest-risk exception class.
3. Decide whether the controller should allow close.
4. State the owner, SLA, escalation path, and evidence requirement.

## Teaching cues

- Unmatched value matters more than raw exception count.
- Pending reversals and settlement-date gaps often matter more for close risk than small fee differences.
- A scoring or recommendation signal is not approval.
- Reconciliation is a finance-controls problem before it is a technology problem.

## Expected output

Participants should produce:

- close or no-close recommendation
- materiality view
- top root cause
- named owner
- escalation path
- approval decision
