About: Working Capital Control Tower

Concept, learning objectives and how to adapt this demo to your data

Overview

An agent swarm turns five ordinary finance exports — open invoices, payment history, a bank statement, supplier invoices, operating outflows — into a collections plan, a reconciled cash position, a 13-week forecast and a funded borrow/invest plan for a fictional mid-market manufacturer (Kaveri Auto Components Ltd, INR).

The architecture idea (the part worth stealing)

Deterministic core, agentic shell. Every number is computed by plain, auditable code: quantile ML for payment dates, a five-rung reconciliation ladder, direct cash-flow math, a greedy treasury planner. Agents decide, delegate and explain — they never produce a figure. This page replays pre-computed results of that pipeline; the live tier runs it for real with a multi-provider agent swarm on top.

Learning objectives

  • See why forecast quality is a funding cost: the treasury plan holds a cash cushion sized to the P50–P90 uncertainty band, so narrower predictions mean less standby borrowing (flip the AI toggle: peak draw falls ₹14.9 cr → ₹12.5 cr).
  • Understand reconciliation as an exception-queue discipline: auto-matching is plumbing; the value is a scored queue that tells a human exactly what evidence clears each item.
  • Read a working example of governed agent design: specialists with narrow tools, an orchestrator with judgment, humans holding every signature.

The business decision it supports

How much working-capital line do we really need this quarter, which invoices do we chase first, and which early-payment discounts are worth taking against a 9.5% cost of funds?

Run modes

Browser (this page): pre-computed simulation, no setup, no keys.
Live tier (registered participants): the full Python pipeline, Streamlit control tower and agent swarm (Anthropic / OpenAI / OpenRouter / Groq via a .env file), with seeded synthetic data you can regenerate — or replace with your own ERP exports via a column-mapping file.

How to adapt this demo to your use case

The live tier validates eight CSV contracts (customers, open invoices, invoice history, bank transactions, remittance advice, suppliers, supplier invoices, operating outflows). Export those from your ERP, map your headers once in a YAML file, and the same pipeline — predictions, reconciliation, forecast, funding plan — runs on your business. A data steward step reports anything missing before a single number is computed.
