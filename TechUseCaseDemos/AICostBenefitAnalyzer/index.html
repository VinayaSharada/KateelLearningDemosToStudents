AI Cost Benefit Analyzer

Students can build a simple AI investment case by entering implementation costs, expected transaction volume, and efficiency gains, then interpreting NPV, ROI, and payback outputs.

Runs fully in browser NPV and ROI model Decision recommendation

What this demo is about

AI adoption decisions should account for full implementation cost, expected value creation, and time to recover the investment.

Learning objectives

  • Translate project assumptions into a financial model.
  • Interpret NPV, ROI, and payback together instead of separately.
  • Challenge optimistic AI business-case assumptions.

Input Variables

Inputs represent simplified assumptions. Personnel cost is calculated as hours multiplied by hourly rate before being added to data and compute costs.

Decision Button

Calculate Business Case runs a 3-year discounted cash-flow approximation and generates a recommendation based on ROI and payback speed.
