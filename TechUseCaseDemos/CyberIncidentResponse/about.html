About: Cyber Incident War Room

Concept, learning objectives and how to adapt this demo to your fleet

Overview

A critical RCE (fictional CVE-2026-77777 in the fictional "JollyHTTP" framework) is announced with an exploit in the wild. Seven systems at a fictional manufacturer run vulnerable versions; the internet-facing dealer portal shows exploit signatures — and two got through, exposing 182,000 dealer PII records. The CERT-In six-hour filing clock starts at detection. An incident swarm scopes, sequences and drafts; every consequential button stays human.

The architecture idea (the part worth stealing)

Compression without transfer of authority. The blast radius is an SBOM×CVE join; compromise-vs-attempt is a log-evidence distinction; the response plan is priced sequencing. Agents turn the fog hour into eleven minutes of staged drafts — the isolation order, the CERT-In filing, the dealer note — and execute none of them.

Learning objectives

  • Boring inventories are crisis assets: scoping took seconds because the software inventory existed.
  • Evidence, not vibes: "attempted" vs "likely compromised" is a log-level distinction with a ₹-crore consequence — see the 403s vs the 200s.
  • Price the downtime, unlock the decision: isolation moves when it is ₹24.5 lakh vs 182,000 records, not a feeling.
  • The filing comes before the fix: systems clear at T+16h, ten hours after the regulatory report is due — preparation is everything.

Run modes

Browser (this page): pre-computed incident, no setup, no keys, with a regulatory-countdown slider.
Live tier (registered participants): the full Python scoping/sequencing pipeline, Streamlit war room, and the incident agent swarm that drafts the actual CERT-In filing text (Anthropic / OpenAI / OpenRouter / Groq via a .env file).

How to adapt this demo to your use case

Six CSV contracts match what a CMDB, SBOM tool and WAF already export: asset inventory, software BOM, vulnerability feed, access events, data map, patch catalog. Load an anonymized slice of your fleet and run this as the quarterly tabletop — same fictional CVE, your real approval chain; time how long the signatures take.
