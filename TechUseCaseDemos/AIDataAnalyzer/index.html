AI Data Analyzer

Students can paste a small CSV dataset, generate baseline descriptive statistics, and compare them with an AI-style narrative focused on trends, anomalies, insights, or forecasting.

Runs fully in browser CSV paste workflow Traditional vs AI comparison

What this demo is about

Analytics work often needs both structured statistics and narrative interpretation. This demo helps students compare those two modes directly.

Learning objectives

  • Read summary statistics before jumping to conclusions.
  • See how prompt focus changes AI-style interpretation.
  • Discuss what still needs human validation.

Input Variables

Input explanation: the first row is treated as column names. Numeric columns are summarized statistically, and the selected focus steers the AI-style interpretation.

Decision Button

Analyze Dataset computes traditional summary statistics first, then adds an AI-style interpretation if the toggle is enabled.

Output and Explanation

Traditional analysis

AI interpretation

What to notice: the table answers “what happened numerically,” while the AI block attempts “what it might mean.” Students should validate the second using the first.
