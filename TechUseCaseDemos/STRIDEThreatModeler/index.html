How to use this demo

Build and analyze threat models

STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege) is a systematic threat modeling methodology.

Step 1: Design Your DFD

  • Click "Add Entity" and select entity type
  • Click on the canvas to place entities
  • Configure entity security properties (authentication, encryption, validation)
  • Use "Add Data Flow" to connect entities and label connections

Step 2: Configure Security Properties

  • Set protocol for each data flow (HTTP, HTTPS, SSH, etc.)
  • Mark data as encrypted or crossing trust boundaries
  • Check if data flows are sensitive (credentials, PII)
  • Enable entity-level controls (auth, validation, logging)

Step 3: Analyze & Mitigate

  • Click "Analyze Threats" to auto-generate STRIDE threats
  • Review threats grouped by STRIDE category
  • Read mitigation strategies for each threat
  • Update your DFD and re-analyze

STRIDE Categories

  • Spoofing - Identity spoofing attacks
  • Tampering - Data modification attacks
  • Repudiation - Denial of actions
  • Information Disclosure - Privacy breaches
  • Denial of Service - Availability attacks
  • Elevation of Privilege - Unauthorized access

Data Flow Diagram Elements

  • External Actor: Users or systems outside your control
  • Process: Application logic or middleware
  • Data Store: Databases, file systems, caches
  • Trust Boundary: Mark data flows crossing security boundaries

Learning Outcomes

  • Apply STRIDE methodology systematically
  • Identify threat patterns from architecture
  • Map threats to mitigations and controls
  • Integrate threat modeling into design decisions
