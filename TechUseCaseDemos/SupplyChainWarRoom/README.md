# Supply-Chain Disruption War Room — Agent Swarm Simulation

Browser-first demo: a compound disruption (port congestion + a supplier
fire) hits a fictional manufacturer, and a war-room agent swarm derives
line-stop dates, prices every mitigation lever (air uplift / alternate
supplier / accept) and stages the customer communications — stopping at the
human approvals. Four pre-computed scenarios; no network calls, no keys.

## Learning objectives

- Scenario latency is a strategic asset: "what if it gets worse?" becomes an
  instant re-derivation instead of a three-day exercise.
- Price the levers, then decide — including the honest accept-and-communicate
  case where no economic fix exists.
- The swarm mirrors the org chart: agents analyze and draft; the ₹-crore
  signatures stay human.

## Run modes

- **Browser** (this folder): open `index.html`. No setup.
- **Live tier**: registered executive-education participants get the full
  scenario engine with shock sliders, Streamlit war room and multi-provider
  agent swarm, adaptable to their own MRP exports (nine CSV contracts).

## Expected setup time

0 minutes (browser). Demo type: interactive simulation with a four-scenario
selector and an animated swarm timeline.
