# Month-End Close Forensics — Agent Swarm Simulation

Browser-first demo: three over-budget lines at a fictional manufacturer's
month-end close, attributed with evidence by a forensic agent swarm —
✅ APPROVED (a freight expedite with a COO+CFO signature), 🔴 AVOIDABLE LEAK
(a GPU retraining deploy on on-demand rates while a 48% savings plan sat
unused; ₹8.8 lakh recoverable), 🟡 PROCESS GAP (duplicate BI + 95-day-idle
seats). Includes the **🎭 Swarm Replay**: an event-sourced animation of the
actual recorded run — nothing scripted. All data pre-computed and synthetic;
no network calls, no keys.

## Learning objectives

- Classify before you convene: red ink is three different conversations.
- The evidence lives outside Finance — billing × deploy log × contract
  clause × approvals register × usage telemetry.
- A variance with a signature is governance working, not failing.

## Run modes

- **Browser** (this folder): open `index.html`. No setup.
- **Live tier**: registered executive-education participants get the full
  pipeline (threshold slider) and run the swarm live in the Swarm Theater —
  adaptable to their own ERP/cloud/git/SSO exports (seven CSV contracts).

## Expected setup time

0 minutes (browser). Demo type: interactive simulation with variance scan,
forensic findings, a billing×deploy drill-down chart and a recorded
swarm-trace replay.

Open `index.html` in any modern browser, or serve the folder statically.
