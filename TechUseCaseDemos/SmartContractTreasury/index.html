🚀 Getting Started

This demo requires local execution. Follow these steps:

  • 1. Clone the repository: git clone https://github.com/VinayaSharada/KateelLearningDemosToStudents.git
  • 2. Navigate to this demo folder
  • 3. Read the README.md for setup instructions
  • 4. Install required dependencies
  • 5. Run the demo locally

📋 Key Features

  • Interactive browser-based interface
  • No cloud services required
  • Open-source and free to use
  • Customizable for your courses
