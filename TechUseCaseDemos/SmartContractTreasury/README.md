# Smart Contract Treasury

## Overview
Treasury operations on blockchain demo showcasing smart contract execution for payments and automated workflows.

## Learning Objectives
- Understand smart contract execution for treasury payments
- Learn multi-signature wallet operations
- Explore automated treasury workflows
- Analyze transparency and audit trails in blockchain treasury

## Features
- **Smart Contract Payments**: Execute payments via smart contracts
- **Multi-sig Wallets**: Secure treasury wallets with multi-signature
- **Automated Workflows**: Programmatic treasury operations
- **Audit Trail**: Transparent transaction history

## How to Run
1. Open `index.html` in a browser
2. Connect wallet (simulated)
3. Execute treasury operations
4. View transaction history

## Smart Contract Functions
- `executePayment(recipient, amount, token)`
- `approveTransaction(txId)`
- `rejectTransaction(txId)`
- `getBalance(token)`

## Security Considerations
- Multi-signature requirements for large transactions
- Time-lock for pending approvals
- Event logging for audit purposes
