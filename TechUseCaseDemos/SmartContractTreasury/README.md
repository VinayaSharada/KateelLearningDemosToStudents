# Smart Contract Treasury Operations

## Overview
Browser-based hands-on exercise for Blockchain & Smart Contracts (Sessions 5-6).

## Learning Objectives
- Understand smart contract automation
- Experience decentralized treasury operations
- Learn blockchain governance principles
- Practice multi-signature workflows

## Features
- **Wallet Connection**: Simulated wallet with token balances
- **Multi-sig Payments**: Execute and approve transactions
- **Transaction History**: View completed and pending transactions
- **AI Security Insights**: Fraud risk assessment and recommendations
- **Export Functionality**: Download results as JSON

## How to Run
1. Open `index.html` in a browser
2. Select a treasury scenario
3. Execute multi-sig payments
4. Approve/reject pending transactions
5. Review AI security insights
6. Export results if needed

## Scenarios Included
| Scenario | Description | Transactions |
|----------|-------------|--------------|
| Daily Operations | Frequent small transactions | 5/day |
| Monthly Settlement | Consolidated payments | 1/month |
| Quarterly Treasury | Large settlements | 1/quarter |
| Custom | User-defined | Variable |
