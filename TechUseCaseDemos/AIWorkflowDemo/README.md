# AI Workflow Demo

Browser-based finance workflow demo for deciding how an AI-supported process should route work, where human review is required, and what exception path protects finance control objectives.

## Decision focus

The demo is designed around one finance question:

`Which workflow design gives speed without weakening approval, evidence, or judgement controls?`
