# AI Workflow Demo

Browser-based finance workflow demo for deciding how an AI-supported process should route work, where human review is required, and what exception path protects finance control objectives.

## Decision focus

The demo is designed around one finance question:

`Which workflow design gives speed without weakening approval, evidence, or judgement controls?`

## Included guidance files

- `about.html`
- `index.html`
- `instructor-guide.md`
- `participant-task.md`
- `expected-answer.md`

## What you can enhance on your own

- Add more workflow patterns, service-level timers, and exception branches.
- Add exportable workflow maps with owner, approval point, and escalation rule.
- Add side-by-side comparisons for faster routing versus stronger control coverage.
- Add role-specific views for controller, process owner, reviewer, and faculty facilitation.

## How to adapt this demo to your use case

- Replace the sample workflow scenarios with the process and exception logic relevant to your organization or course.
- Decide where speed is valuable and where human review must remain mandatory.
- Keep the workflow output advisory until process owners confirm the routing, evidence, and approval design.
- Use the same demo across CFO, controllership, AI/ML, operations, and classroom settings by changing the workflow case around the shared routing logic.
